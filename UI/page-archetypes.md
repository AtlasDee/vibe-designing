# 页面原型与字段映射

## 选择原型

| 原型 | 识别信号 | 标准页面 | 常用弹窗 |
| --- | --- | --- | --- |
| 运营工作台 | 手机预览、场景选择、AI 助手 数据联动 | 运营后台首页、页面和组件下钻 | 数据抽屉、配置弹窗或全屏编辑器 |
| CRUD 管理 | 管理一类主数据，需要增删改查 | 部门、岗位、参数、业务管理员 | 400–600px 表单弹窗 |
| 权限配置 | 角色、菜单、数据范围、层级或树形勾选 | 角色、菜单、数据权限 | 600–900px，树、双栏或分区表单 |
| 日志查询 | 以时间、操作人、系统、行为查询为主，记录只读 | 系统、审计、注册、登录、操作日志 | 详情弹窗，展示参数和响应 |
| 接入/配置 | 密钥、回调地址、权限范围、应用与业务线关联 | 终端、字典、应用、应用业务线 | 400–1000px，复杂字典项使用宽弹窗 |

## 运营工作台原型

结构：顶部一级导航、左侧运营模块导航、中间手机页面预览、右侧面包屑与 AI 助手 上下文区，以及右侧底部固定的 AI 输入栏。

- 手机是业务对象选择器，必须与右侧内容联动。
- 面包屑、左侧选中态、手机选中态和右侧消息保持一致。
- 场景列表、账号、问候时段和指标均按动态数据处理。
- 详细规则读取 [operations-home-workbench.md](operations-home-workbench.md)。

## CRUD 管理原型

页面结构：关键字/归属/状态查询，新增主按钮，数据表，行编辑和删除，分页。

弹窗结构：基本标识、显示名称、归属关系、描述/备注、状态、排序。

- 新增成功后返回符合当前筛选的页码，并使新记录可见。
- 编辑保留当前页码和筛选。
- 删除前显示对象名称；有下级或被引用时阻止删除并说明关联。

## 权限配置原型

页面结构：角色/系统/业务线查询，角色表格，功能权限与数据权限入口。

- 功能权限使用菜单树，显示半选、全选、展开/收起和关键字筛选。
- 数据权限用层级、业务线、部门或自定义范围表达，不将功能权限和数据权限混在一棵树中。
- 保存前显示当前对象和变更摘要；大范围授权需要额外确认。
- 无权限的树节点不允许被间接勾选。

## 日志查询原型

查询条件：系统/业务线、操作人、操作类型、IP、时间范围、关键字。时间范围是高优先级字段。

表格字段：时间、系统/菜单、操作人、IP、行为、结果、耗时、详情。

- 默认按时间倒序。
- 详情只读，长参数与响应使用格式化内容和复制操作。
- 导出必须继承当前筛选，并对敏感字段脱敏。
- 除明确合规策略外，不在行内提供编辑或删除。

## 接入/配置原型

页面结构：应用/系统查询，接入对象表格，新增/编辑弹窗，密钥、回调和权限范围的特殊处理。

- 密钥类字段默认掩码，查看或复制需要独立权限，必要时记录审计日志。
- URL 字段验证 `http/https`、最大长度和多值分隔；回调地址明确是否允许多个。
- 权限范围使用多选或勾选列表，自动授权使用开关或单选，不用自由文本代替。
- 重置/再生成密钥是高风险操作，说明旧密钥失效时间和影响。

## 现有页面字段索引

| 页面 | 关键字段/交互 |
| --- | --- |
| 用户管理 | 用户名、手机号、SSO、部门、岗位、角色权限、系统/业务线、状态、动态令牌设备、绑定/解绑、导出、列显隐 |
| 业务管理员 | 管理员、系统、角色、SSO、状态、启停用时间 |
| 菜单管理 | 系统、业务线、菜单中英文名称、图标、排序、路由、类型、缓存、权限标识/名称/说明/值 |
| 数据权限 | 系统、业务线、层级、权限值与说明 |
| 角色管理 | 角色名、标识、描述、系统、业务线、功能权限、数据权限、关键字和时间筛选 |
| 部门管理 | 部门名、上级部门、排序、审计字段；使用树表 |
| SSO 域账号 | SSO 账号、系统列表、文件名，支持导出当前/全部 |
| 岗位管理 | 岗位名、岗位编码、职责描述、排序、审计字段 |
| 系统日志 | 类型、IP、标题、请求、客户端、请求时间；查询、导出，特殊情况下删除 |
| 审计/注册/登录日志 | 系统类型、系统、域、操作人、IP、操作名/类型/行为、参数、响应、时间、耗时 |
| 操作日志 | 一级菜单、二级菜单、操作人、操作类型、参数、响应、时间、耗时 |
| 终端管理 | client ID/secret、scope、授权类型、回调地址、权限、自动批准、access/refresh token 有效期、扩展信息、资源 ID |
| 字典管理 | 字典键、描述、系统标识、备注；字典项包含数据值、标签、展示类型、排序 |
| 参数管理 | 名称、键、值、编码、系统类型、状态、参数类型 |
| 应用管理 | 应用标识、中英文名称、中英文描述、Logo；先输入应用名再获取数据的场景要明确空态 |
| 应用业务线 | 应用、业务线、系统标识中英文名称、地址、URL；验证 http/https 与长度 |
